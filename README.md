Task Manager
Descrição:

Este projeto consiste numa aplicação de gestão de tarefas desenvolvida com:

- React (Frontend)
- Node.js + Express (Backend)
- MariaDB (Base de dados)

A aplicação permite realizar operações CRUD (Create, Read, Update, Delete) sobre tarefas.


Tecnologias utilizadas:

- Node.js
- Express
- React
- Axios
- MariaDB
- Postman
